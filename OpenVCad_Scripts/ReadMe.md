# OpenVCad_Scripts:

These are all previously used OpenVCad scripts used to generate .png stacks. The majority of these are out of date and generated using some version of [FouierCalculation2.2_FileGenerator.ipynb](../Fourier_Series_Generator/FouierCalculation2.2_FileGenerator.ipynb). If you are interested in printing a specific material gradient is likely easier to create a new version of the OpenVCAD Script using the previously mentioned script.

Records of prints made using these scripts can be found on the MACLab OneDrive [here](https://o365coloradoedu-my.sharepoint.com/:w:/r/personal/maccurdy_colorado_edu/Documents/G/MacCurdy%20Lab/Lab%20Projects/Printable%20Hydraulics%20Designs/printingNotes.docx?d=wa51fb766155d454ca0a2b89b98a6ae08&csf=1&web=1&e=bFy1dS).
